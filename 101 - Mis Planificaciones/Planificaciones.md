# Planificaciones de Entrenamiento

Registro cronológico de las sesiones planificadas por el entrenador. Cada sesión mantiene la notación original del coach.

## Cómo leer la notación

- **`peso/reps`** → carga en kg / repeticiones. Ej: `40/3` = 3 reps con 40 kg.
- **`xN`** → número de series. Ej: `40/3x2` = 2 series de 3 reps con 40 kg.
- **`a+b`** → complejo dentro de la misma serie. Ej: `30/1+3` = 1 + 3 reps con 30 kg (movimiento combinado).

**Abreviaturas frecuentes** (interpretación de apoyo, no altera el dato original):

| Abreviatura | Significado |
|---|---|
| Arr | Arranque |
| Envión / Envion | Envión |
| Carg | Cargada |
| Pot | Potencia (sin recepción profunda) |
| Técnico / Tecnico | Ejercicio técnico (recepción completa) |
| colg | Colgada (desde suspensión) |
| b/rod | Bajo (debajo de) la rodilla |
| s/rod | Sobre la rodilla |
| s/despl | Sin desplazamiento de pies |
| 1/2 tirón | Medio tirón |
| Tirón Arr / Tirón Envión | Tirón de arranque / de envión |
| Sentadillas x del | Sentadilla por delante (frontal) |
| Overhead | Sentadilla overhead (por encima de cabeza) |
| 2do tpo | Segundo tiempo (envión desde el pecho) |
| c/ tijera | Con tijera |
