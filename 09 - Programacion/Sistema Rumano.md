# Sistema Rumano de Entrenamiento

## Contexto

El sistema rumano, bajo la dirección de entrenadores como Dragomir Ciroslan y el sistema OTC (Olympic Training Center de EEUU), es una aproximación al entrenamiento que equilibra periodización estructurada con intensidad alta.

## Distribución de intensidad (Ciroslan)

La base del sistema es una distribución prescrita de repeticiones por zona de intensidad:

| Zona | % del máximo | Proporción de repeticiones |
|---|---|---|
| Desarrollo de fuerza | 75-85% | 60% |
| Alta intensidad | 86-95% | 35% |
| Máxima | 96-100%+ | 5% |

Esta distribución es una guía para el mesociclo, no para cada sesión individual.

## Características del sistema

### Periodicidad estructurada
- A diferencia del búlgaro, el rumano usa periodización explícita (macrociclo → mesociclo → microciclo)
- Los mesociclos siguen un patrón de carga progresiva con semanas de descarga planificadas

### Variedad de ejercicios
- El sistema rumano incluye una gama más amplia de ejercicios accesorios que el búlgaro
- Sentadillas (frente y atrás), tirones, cargadas desde bloques, arranques desde bloque, ejercicios de empuje

### Volumen moderado, frecuencia moderada
- Menos sesiones por día que el sistema búlgaro (2-3 sesiones/día en atletas de élite)
- Más recuperación planificada entre sesiones

## El concepto de máximo competitivo vs. entrenamiento

- En el sistema rumano, los atletas no necesariamente van al máximo absoluto en cada sesión
- Existe distinción entre el máximo de entrenamiento y el máximo competitivo
- La semana de competencia reduce drásticamente el volumen para expresar el máximo potencial

## Aplicación en el contexto americano

El OTC adoptó elementos del sistema rumano como base para el programa nacional de EEUU:
- Adaptado para atletas que no viven en centros de entrenamiento
- Distribuido en programas de 3-6 sesiones semanales
- La distribución de intensidad de Ciroslan se usa como referencia para evaluar la "calidad" de los programas de entrenamiento
