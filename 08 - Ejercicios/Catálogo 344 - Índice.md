# Catálogo 344 — Índice

Punto de entrada al catálogo completo de [[Buitrago - 344 Ejercicios Chinos]]: los **344 movimientos** que los centros de halterofilia de China usan en las distintas etapas de desarrollo del atleta.

> [!tip] Leé esto primero
> No abordes el catálogo como una lista. Los 344 son el producto de **seis ejes que se multiplican entre sí**. Entender la gramática vale más que memorizar el vocabulario.

| Bloque | Movimientos | % |

La proporción es el dato: **el sistema chino es abrumadoramente específico.** El culturismo entra como complemento con criterios explícitos, nunca como base. → [[Culturismo en el Sistema Chino]]

## Vocabulario mínimo

| Término | Significado exacto en el catálogo |
|---|---|
| **Power** | Recepción **por encima** de 90° de flexión de rodilla. |
| **Half / medio** | Recepción **a ~90°**. |
| **Muscle** | Recepción con **piernas rectas**. |
| **En la rodilla** | Barra a la altura del **tendón rotuliano**. |
| **Arriba de rodilla** | Barra en el **vientre del VMO**. |
| **Contacto** | Pliegue de cadera (arranque) · **5–10 cm por debajo** (cargada). |
| **Risers** | Tarima **bajo el atleta** → más rango. |
| **Bloques** | Soportes **bajo la barra** → menos rango. |
| **No touch / floating** | La barra nunca descansa → tensión continua. |
| **Sin split** | Los pies **no cambian de ancho** al recibir. |
