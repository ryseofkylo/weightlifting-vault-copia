# Táctica en Competencia

## Principio fundamental

**Tu atleta intenta el mínimo necesario para ganar. El rival debe intentar el máximo posible.**

- Esto minimiza el riesgo de falla de tu atleta
- Maximiza la presión sobre el rival para que intente pesos difíciles

## Uso del orden de turno

El orden de llamada en competencia depende de:
1. Peso en la barra (ascendente)
2. Número de intento (primero, segundo, tercero — los de menor intento van antes)
3. Mayor diferencia de salto desde el intento anterior
4. Número de lote (sorteo)

**Aplicación táctica:** si puedes manipular los saltos de manera que tu atleta sea llamado después que el rival, obtenés información sobre si el rival falló o tuvo éxito antes de necesitar comprometerte con tu tercer intento.

## Información como arma

- Saber el total actual del rival antes de cada intento permite ajustar el intento propio
- Un entrenador que conoce el reglamento puede usar las reglas de orden para crear ventajas

## Prohibición de coerción

Drechsler es explícito: **el atleta tiene derecho a tomar la decisión final sobre el peso**. El entrenador no debe coaccionar. No hay valor en forzar un intento que el atleta no quiere hacer — ninguna ganancia táctica lo justifica si el atleta no está convencido.

## Reglas de tiempo a recordar

- **1 minuto** para hacer el intento una vez llamado
- **2 minutos** si el levantador repite el mismo peso (sigue a sí mismo)
- Si pedís un cambio de peso y se llama a otro levantador, volvés con 1 minuto
- Si pedís cambio y quedás en plataforma, el reloj se detiene mientras cargan
- Advertencia sonora a los **30 segundos** — después no se permiten cambios de peso
